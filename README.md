Hangman Game - Python

About the Project

Hangman is a word-guessing game developed using Python. Players guess a hidden word one letter at a time.

Features

- Three difficulty levels: Easy, Medium, and Hard
- Random word selection
- Score tracking
- Guessed letter tracking
- Input validation
- Replay option

Technologies Used

- Python 3
- Random module

How to Run

1. Install Python 3 or open the project in Pydroid 3.
2. Run the "hangman1.py" file.
3. Select a difficulty level.
4. Guess the hidden word one letter at a time.
5. Choose whether to play again.
